# Проект "Сервис доставки еды"
# Назначение системы:
Система предназначена для автоматического распределения заказов между курьерами с учётом: расстояния до ресторана и клиента, текущей загруженности курьера, его рейтинга и направления движения. Также система обеспечит клиенту возможность отслеживать заказ в реальном времени и связываться с рестораном или курьером через встроенный чат или по мобильному телефон.
## Пользователи
Клиент, ресторан, доставщик, диспетчер

## ## Основные возможности 
1. Оформление и оплата заказа с ограничением радиуса доставки (до 10 км).
2. Автоматическое распределение заказов и отслеживание геолокации курьера.
3. Управление заказами со стороны ресторана (приём, передача курьеру).
4. Просмотр загруженных зон и ручной выбор заказов курьером.
5. Панель диспетчера: ручное переназначение заказов, решение сбоев и конфликтов.
6. Встроенный чат и push-уведомления для всех участников процесса.
