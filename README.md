Проект "Сервис доставки еды"
Назначение системы:
Система предназначена для автоматического распределения заказов между курьерами с учётом: расстояния до ресторана и клиента, текущей загруженности курьера, его рейтинга и направления движения. Также система обеспечит клиенту возможность отслеживать заказ в реальном времени и связываться с рестораном или курьером через встроенный чат или по мобильному телефон.
